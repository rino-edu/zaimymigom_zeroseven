# Функции мобильного приложения "ЗаймыМигом"

## 1. Калькулятор полной стоимости кредита(Готово)

### Описание
Инструмент для расчета полной стоимости кредита (ПСК) с учетом всех комиссий, процентных ставок и дополнительных платежей.

### Основные возможности:
- **Ввод параметров кредита**: сумма займа, процентная ставка, срок кредитования, тип платежей (аннуитетные/дифференцированные)
- **Учет дополнительных платежей**: единоразовые комиссии при выдаче, ежемесячные комиссии за обслуживание, страховка (при наличии)
- **Расчет ПСК**: автоматический расчет полной стоимости кредита в процентах годовых согласно требованиям ЦБ РФ
- **Детализация платежей**: помесячный график погашения с разбивкой на основной долг, проценты и комиссии
- **Примечание**: пользователь не может ввести годовую процентную ставку больше 36%.

## 2. Ведение бюджета (готово)

### Описание
Система учета доходов и расходов для контроля финансового состояния и управления личными финансами.

### Основные возможности:
- **Учет доходов**:
  - Добавление различных источников дохода (зарплата, подработка, дивиденды и т.д.)
  - Категоризация доходов для удобной аналитики
  - Регулярные и разовые доходы с возможностью настройки автоматического добавления
  
- **Учет расходов**:
  - Ручной ввод расходов с указанием категории (продукты, транспорт, развлечения, коммунальные услуги и т.д.)
  - Быстрое добавление частых расходов через шаблоны
  - Добавление фотографий чеков для подтверждения расходов
  - Поддержка как разовых, так и регулярных расходов (подписки, абонементы)
  
- **Категории и теги**:
  - Гибкая система категорий с возможностью создания подкатегорий
  - Кастомные теги для дополнительной организации данных
  - Цветовая маркировка категорий для визуального различения
  
- **Планирование бюджета**:
  - Установка месячных/недельных лимитов по категориям
  - Уведомления о приближении к лимиту или его превышении
  - Сравнение плановых и фактических показателей

## 3. Генератор финансовых целей(готово)

### Описание
Инструмент для постановки финансовых целей и отслеживания прогресса их достижения.

### Основные возможности:
- **Создание целей**:
  - Установка названия цели и целевой суммы
  - Выбор дедлайна (дата достижения цели)
  - Приоритизация целей (важные, средние, низкие)
  - Добавление фотографии/иконки для визуализации цели
  
- **Отслеживание прогресса**:
  - Визуальный индикатор прогресса (процент выполнения, прогресс-бар)
  - История пополнений с возможностью добавления комментариев
  - Автоматическое или ручное перераспределение средств из бюджета в цели
  
- **Планирование накоплений**:
  - Расчет необходимой суммы ежемесячных отчислений для достижения цели к установленному сроку
  - Рекомендации по корректировке целей при изменении финансовой ситуации
  - Создание нескольких целей одновременно с автоматическим распределением средств
  
- **Уведомления и мотивация**:
  - Напоминания о необходимости пополнения цели
  - Поздравления при достижении вех (25%, 50%, 75%, 100%)
  - Статистика по завершенным целям

## 4. Конвертер валют

### Описание
Инструмент для быстрого перевода одной валюты в другую по актуальным курсам.

### Основные возможности:
- **Поддержка популярных валют**:
  - Основные валюты: RUB, USD, EUR, GBP, CNY, JPY и другие
  - Криптовалюты (опционально): BTC, ETH и т.д.
  - Редкие валюты по запросу
  
- **Актуальные курсы**:
  - Автоматическое обновление курсов валют в реальном времени
  - Возможность ручного обновления курсов
  - Отображение времени последнего обновления
  - Индикация изменения курса (рост/падение) за период
  
- **Функциональность**:
  - Быстрый ввод суммы с удобным калькулятором
  - Обратный расчет (конвертация в обе стороны)
  - Сохранение избранных валютных пар для быстрого доступа
  - История последних конвертаций
  
- **Дополнительно**:
  - График изменения курса за период (день, неделя, месяц, год)
  - Уведомления об изменении курса на заданный процент
  - Расчет комиссии при обмене валют в обменных пунктах

## 5. Финансовый календарь

### Описание
Календарь важных финансовых событий с напоминаниями о сроках платежей и обязательств.

### Основные возможности:
- **Отображение событий**:
  - Календарный вид с отметками важных дат
  - Список предстоящих событий на неделю/месяц
  - Фильтрация по типам событий (займы, подписки, платежи, цели и т.д.)
  
- **Типы событий**:
  - Сроки погашения займов и кредитов
  - Продление подписок и абонементов
  - Регулярные платежи (коммунальные, связь, интернет)
  - Дедлайны финансовых целей
  - Важные финансовые операции
  
- **Уведомления**:
  - Push-уведомления за определенное время до события (настраиваемый интервал)
  - Ежедневные напоминания о событиях текущего дня
  - Напоминания о просроченных обязательствах
  
- **Интеграция с другими функциями**:
  - Автоматическое добавление событий из раздела "История займов"
  - Связь с функцией ведения бюджета для планирования платежей
  - Связь с генератором целей для отслеживания дедлайнов

## 6. Оценка кредитоспособности

### Описание
Упрощенный тест для самопроверки финансового состояния перед взятием займа.

### Основные возможности:
- **Анкетирование**:
  - Вопросы о текущем финансовом положении (доходы, расходы, наличие сбережений)
  - Оценка кредитной истории (наличие текущих займов, просрочек)
  - Анализ финансовой дисциплины (регулярность доходов, планирование бюджета)
  
- **Расчет показателей**:
  - Оценка платежеспособности (соотношение доходов и обязательных расходов)
  - Расчет доступной суммы для займа
  - Оценка рисков неплатежеспособности
  - Рекомендации по улучшению кредитоспособности
  
- **Результаты и рекомендации**:
  - Вывод итогового балла кредитоспособности
  - Визуализация сильных и слабых сторон финансового состояния
  - Персональные рекомендации по улучшению показателей
  - Рекомендации по оптимальной сумме и сроку займа
  
- **История оценок**:
  - Сохранение результатов предыдущих оценок
  - Отслеживание динамики изменения кредитоспособности
  - Сравнение показателей за разные периоды

## 7. Финансовые советы

### Описание
Раздел с краткими советами и рекомендациями по управлению деньгами и финансовому планированию.

### Основные возможности:
- **Категории советов**:
  - Управление бюджетом и экономия
  - Кредиты и займы (как взять, как погасить, как избежать долговой ямы)
  - Накопления и инвестиции
  - Финансовая грамотность
  - Защита от мошенничества
  
- **Формат контента**:
  - Краткие статьи с практическими советами
  - Пошаговые инструкции
  - Чек-листы для проверки финансового здоровья
  - Инфографика и визуальные материалы
  
- **Персонализация**:
  - Рекомендации на основе финансового профиля пользователя
  - Советы, релевантные текущей финансовой ситуации
  - Приоритизация тем в зависимости от активности пользователя
  
- **Интерактивность**:
  - Возможность сохранения понравившихся советов в избранное
  - Поиск по ключевым словам
  - Фильтрация по тематикам
  - Ежедневные/еженедельные подборки актуальных советов

## 8. История займов

### Описание
Архив всех оформленных займов с детальной информацией и возможностью отслеживания статуса.

### Основные возможности:
- **Информация о займах**:
  - Полная информация по каждому займу: сумма, процентная ставка, срок, дата оформления
  - Текущий статус займа (активный, погашен, просрочен)
  - История платежей с детализацией
  - Остаток задолженности и график погашения
  
- **Организация данных**:
  - Сортировка по дате оформления, сумме, статусу
  - Фильтрация по статусу (активные, погашенные, просроченные)
  - Поиск по ключевым словам или параметрам
  - Группировка займов по кредиторам
  
- **Статистика**:
  - Общая сумма всех займов
  - Общая сумма переплат по всем займам
  - Средний процент по займам
  - Графики динамики задолженности
  
- **Дополнительные функции**:
  - Экспорт истории в PDF или Excel
  - Добавление заметок и комментариев к каждому займу
  - Прикрепление документов (договоры, выписки)
  - Связь с финансовым календарем для автоматического добавления сроков погашения

## 9. Статистика расходов

### Описание
Визуализация расходов пользователя в виде графиков и диаграмм для анализа трат.

### Основные возможности:
- **Типы визуализации**:
  - Круговая диаграмма по категориям расходов
  - Столбчатые графики для сравнения периодов
  - Линейные графики для отслеживания динамики
  - Тепловая карта расходов по дням месяца
  
- **Периоды анализа**:
  - День, неделя, месяц, квартал, год
  - Произвольный период (выбор начальной и конечной даты)
  - Сравнение периодов (например, этот месяц vs прошлый месяц)
  
- **Фильтрация и группировка**:
  - Фильтрация по категориям расходов
  - Группировка по тегам
  - Исключение определенных категорий из анализа
  - Сравнение доходов и расходов
  
- **Детальная аналитика**:
  - Топ категорий по расходам
  - Средние расходы по категориям
  - Тренды (рост/падение расходов в категориях)
  - Прогнозирование расходов на основе истории
  
- **Экспорт и отчеты**:
  - Сохранение графиков в виде изображений
  - Генерация PDF-отчетов с аналитикой
  - Отправка отчетов на email

## 10. Сканер документов

### Описание
Функция для фотографирования и сохранения важных финансовых документов с возможностью их организации.

### Основные возможности:
- **Сканирование**:
  - Фотографирование документов через камеру смартфона
  - Автоматическое распознавание границ документа
  - Коррекция перспективы и улучшение качества изображения
  - Поддержка сканирования нескольких страниц одного документа
  
- **Распознавание текста (OCR)**:
  - Автоматическое распознавание текста на документах
  - Извлечение ключевой информации (даты, суммы, реквизиты)
  - Поддержка различных типов документов (чеки, договоры, выписки, счета)
  
- **Организация документов**:
  - Категоризация документов (займы, договоры, чеки, выписки, справки и т.д.)
  - Теги для дополнительной организации
  - Поиск по тексту внутри документов
  - Сортировка по дате, типу, названию
  
- **Безопасность**:
  - Шифрованное хранение документов
  - Защита паролем или биометрической аутентификацией
  - Возможность удаленного удаления данных при потере устройства
  
- **Интеграция**:
  - Привязка документов к конкретным займам или транзакциям
  - Автоматическое заполнение форм на основе данных из документов
  - Экспорт документов в различных форматах (PDF, JPG, PNG)

  - Общие вопросы о займах
